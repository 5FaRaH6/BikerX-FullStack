# BikerX – Motorcycle Community Platform

BikerX is a full-stack motorcycle community platform designed to connect riders, organize meetups, and improve riding safety.

The project consists of a mobile application, a web-based admin dashboard, and a RESTful backend API.

## Tech Stack

- **Mobile:** React Native, Expo, TypeScript
- **Admin Dashboard:** React
- **Backend:** ASP.NET Core Web API, C#
- **Database:** MongoDB Atlas

## Key Features

- Ride tracking and ride mode
- Fall detection and emergency contacts
- Motorcycle meetups
- Posts, comments, and likes
- User profiles and social interactions
- Reports and content moderation
- Admin dashboard for platform management
